# Diabetes Risk Prediction — Machine Learning

## Project Overview

This project develops and evaluates machine learning models for diabetes risk prediction using structured patient-related data.

The objective is to build a reproducible classification workflow covering data preprocessing, model development, model comparison, and performance evaluation.

## Objective

The project aims to:

- Prepare and clean the diabetes dataset.
- Handle missing values using median-based treatment where applicable.
- Perform exploratory data analysis.
- Train and compare multiple machine learning classification models.
- Evaluate model performance using appropriate classification metrics.
- Identify a suitable model for diabetes risk prediction.

## Data Preprocessing

The workflow includes data preparation and preprocessing before model training.

Key preprocessing steps include:

- Data quality inspection
- Missing-value treatment using median imputation where applicable
- Feature preparation
- Separation of input features and target variable
- Training and testing data separation

The preprocessing workflow is applied consistently to support reliable model evaluation.

## Machine Learning Models

The project evaluates multiple classification approaches.

Models include:

- AdaBoost Classifier
- Gradient Boosting Classifier
- Other baseline/classification models evaluated in the notebook

Model performance is compared using the evaluation results generated during the analysis.

## Model Evaluation

The models are evaluated using classification performance measures such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The notebook contains the detailed evaluation and comparison of the trained models.

### Model Performance

The analysis identified AdaBoost as one of the stronger-performing models in the evaluated set, with an observed accuracy of approximately 78% in the project evaluation.

Gradient Boosting achieved approximately 75% accuracy in the corresponding evaluation.

These figures are specific to the dataset, preprocessing workflow, train/test configuration, and evaluation performed in this project.
